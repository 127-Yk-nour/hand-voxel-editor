# Hand Voxel Editor 🖐🧊

Draw 3D voxel shapes in the air with your hands. Everything runs in your browser: the camera image never leaves your device.

**Live demo:** https://zemouli-yakout.github.io/hand-voxel-editor/

## How to use
- 🤏 Pinch (thumb + index) and drag: draw cubes
- ✊ Make a fist and move: rotate the model
- 🤏🤏 Pinch with both hands and pull apart / together: zoom
- Big buttons (draw, erase, undo, view, photo, new) are pressed by pinching over them

## Exhibition mode
Four simple gestures, a coach that teaches by success, an attract animation when nobody is there, automatic clean-up for the next visitor, and Arabic / French / English texts. Staff settings are behind the ⚙ button.

## Tech
MediaPipe Tasks Vision (hand landmarks), Three.js (3D), plain HTML/JavaScript in a single file, no build step.

## Hosting
Any static host works (GitHub Pages, Netlify...). The camera needs HTTPS.
